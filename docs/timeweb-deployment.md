# Выкладка Сборки на Timeweb

Обновлено 6 октября 2026. Владелец разрешил перенос в `main` и запуск на Timeweb. Отдельную базу данных отменил: сайт собирает бриф и отправляет заявку только в Telegram. Домен `sborkadigital.ru` владелец добавит после готовности приложения

## Схема

Посетитель → Next.js в Москве → общий ретранслятор в Нидерландах → OpenAI или Telegram

Два приложения App Platform, по одной реплике. PostgreSQL, отдельные серверы БД и миграции для Timeweb не нужны. Node хранит только временное техническое состояние в памяти: счетчики запросов, хеш заявки, статус и позицию доставки. Тексты заявок и контакты в отдельное серверное хранилище не записываются

После перезапуска или нового деплоя ограничения и сведения о доставке сбрасываются. Повторная отправка той же заявки после такого сброса может создать дубль в Telegram. Это принятый компромисс простой схемы, гарантии однократной доставки после рестарта нет. Несколько реплик требуют отдельного решения для общего состояния

Опубликованные сообщения остаются в Telegram. После неоднозначной сетевой ошибки приложение не повторяет отправку автоматически. Пока процесс работает, повторная успешная отправка возвращает прежнее подтверждение, подтвержденные части повторно не отправляются

## Окружение сайта

Секреты задаются при запуске контейнера. Для сборки они не нужны. При создании приложения значения берутся из согласованного защищенного локального файла и передаются в окружение без вывода содержимого в переписку или Git

| Переменная | Значение или назначение |
| --- | --- |
| `PUBLIC_ORIGIN` | `https://sborkadigital.ru` |
| `RELAY_URL` | Выданный HTTPS-адрес общего ретранслятора без пути и параметров |
| `RELAY_SECRET` | Отдельный пароль Сборки из защищенного файла |
| `RELAY_CLIENT` | `sborka` |
| `OPENAI_MODEL` | `gpt-6-luna` |
| `YANDEX_METRIKA_ID` | `113480948` |
| `TRUST_PROXY` | Оставить пустым до проверки ingress |

Сервер сайта не получает ключ OpenAI или токен Telegram. Они находятся на ретрансляторе. Переменные `NEXT_PUBLIC_*` публичны, секреты в них не помещаем. `DATABASE_URL` не используется

Для ретранслятора нужны `OPENAI_API_KEY`, `CLIENT_SBORKA_SECRET`, `CLIENT_SBORKA_TG_BOT_TOKEN`, `CLIENT_SBORKA_TG_CHAT_ID`. Сохраненный получатель Сборки: `-5473838680`. Настройка Flame выполняется отдельным последним шагом, существующие приложения Flame остаются без изменений

## API, контекст и ограничения

Контракт формы сохранен:

- `GET /api/intake/config`: доступность отправки
- `POST /api/intake/next`: следующий вопрос или бриф
- `POST /api/intake/submit`: подтвержденная заявка
- `GET /api/analytics/config`: публичный ID Метрики
- `/api/brief` и `/api/lead`: дополнительные адреса для next и submit

В каждый запрос AI передаются исходная задача и все ответы. Бюджет ожидания 19 секунд, включая чтение тела; допустим один повтор только быстрого сбоя сети, 429 или 5xx. Клиент ждет 22 секунды. Контекст больше 64 КиБ не обрезается: используется локальный бриф, полный диалог остается в заявке

Общий бюджет доставки в Telegram 40 секунд, клиент ждет 45 секунд. Ретранслятор допускает 60 запросов AI и 60 сообщений Telegram в минуту на клиента. На сайте отправка ограничена 5 попытками в час на проверенный IP, без него общим лимитом 30 в час. Общий предохранитель 100 попыток отправки в сутки. Состояние доставки хранится до 30 дней, максимум 5000 записей без вытеснения до истечения срока. Переполнение не считается успешной отправкой

После неопределенного ответа сервера посетитель видит предупреждение о возможном дубле. Действие «Подготовить новую отправку» меняет идентификатор, но ничего не отправляет: контакты и согласие нужно подтвердить снова. При обычном сетевом сбое идентификатор остается прежним. Статус восстановления сохраняется вместе с черновиком во вкладке

Контакты проверяются и подтверждаются посетителем перед отправкой, галочка согласия исходно выключена. Документы владелец отложил, новые юридические страницы не создаются

## Origin и адрес до подключения домена

Origin сравнивается с `PUBLIC_ORIGIN`, а не с произвольным Host. При создании сразу задаем будущий домен. Главная доступна на техническом адресе, но браузерная отправка с него до смены окружения не разрешена. Серверные проверки до привязки домена выполняем на техническом адресе с согласованным Origin. После подключения домена проверяем полный путь в браузере

Если потребуется полноценная форма именно на техническом адресе, владелец может временно изменить `PUBLIC_ORIGIN` в панели на точный выданный адрес, а перед подключением домена вернуть `https://sborkadigital.ru`

Входящие `CF-Connecting-IP`, `X-Forwarded-For` и другие прокси-заголовки не считаются достоверными без явной настройки. При пустом `TRUST_PROXY` действует общий лимит. После подтверждения, что ingress перезаписывает заголовок и недоступен обход, можно задать `x-real-ip` или `xff:N`. Значение `true` не поддерживается

`www.sborkadigital.ru` перенаправляется на основной домен постоянным redirect в standalone-режиме

## Сборка и запуск

```sh
npm ci
npm run lint
npm run test:intake
npm run test:node
npm run test:prefetch
npm run build
npm run build:node
```

Корневой Dockerfile собирает Node 22 standalone. Процесс запускается от пользователя `node`, порт 3000, команда `node server.js`. Отдельной настройки БД и команды миграции нет. Ретранслятор использует свой Dockerfile и порт 8080

Обычная сборка для Sites сохранена. D1 относится только к прежнему размещению на Sites и не требуется для Timeweb

## Порядок запуска

1. Проверить тесты, обе сборки и интерфейс на 390 и 1440 px
2. Перенести проверенные изменения в `main` обычным push. Доступ GitHub App Timeweb к `vc-studio` и `ai-relay` подтвержден 6 октября
3. Создать `shared-relay` в Нидерландах из `ai-relay/main`, автодеплой выключен, секреты задать при создании
4. Проверить `/health`, получить технический HTTPS-адрес ретранслятора
5. Создать сайт в Москве из `vc-studio/main`, включить автодеплой, задать окружение с адресом ретранслятора
6. Проверить развернутый коммит, конфигурацию, AI и доставку сообщения с префиксом `ТЕСТ` в согласованный чат Сборки. После повторного запроса в том же процессе дубля быть не должно
7. Передать владельцу адрес и IP приложения для добавления домена и DNS. После выпуска SSL проверить сайт и отправку с `sborkadigital.ru`

По каталогу Timeweb на 6 октября: минимальное приложение в Москве, preset 2731, 510 рублей в месяц; ретранслятор в Нидерландах, preset 1631, 510 рублей. Для каждого нужен отдельный публичный IPv4, по https://timeweb.cloud/prices 200 рублей в месяц. Предварительный итог 1420 рублей в месяц за новые ресурсы, без расходов OpenAI. Точную цену проверяем перед заказом

Каждая операция записи MCP Timeweb требует отдельного подтверждения возвращенного описания операции. Сразу после создания начинается оплата. Удаление ресурсов и изменение окружения уже созданного приложения доступны только в панели. При первом создании окружение можно передать через MCP

## Откат

Перед публикацией 6 октября прошли 29 проверок intake, 12 проверок Node без БД, 8 проверок предварительных запросов и 19 проверок ретранслятора. Статическая и standalone-сборки завершились успешно. Локальная standalone-версия проверена в браузере на 390 и 1440 px: нет горизонтального переполнения, неопределенная доставка и черновик сохраняются после обновления, новая отправка требует отдельного действия и повторного согласия. В браузерной проверке внешние AI и Telegram заменены тестовыми ответами, фактическая доставка на Timeweb проверяется после создания ресурсов

Вернуть предыдущий рабочий коммит или образ через панель. Сведения о повторах в памяти при перезапуске пропадут, сообщения в Telegram останутся. Не повторять неоднозначную доставку без сверки чата

Старый ретранслятор Flame не удалять. Его перенос согласуется отдельно после проверки Сборки
