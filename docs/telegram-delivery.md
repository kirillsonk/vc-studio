Обновлено 24 сентября 2026

Владелец создал sborka_applications_bot, группу и серверный секрет TELEGRAM_BOT_TOKEN. Токен проверен через getMe, значение не извлекалось из Sites

## Настройка

- TELEGRAM_BOT_TOKEN: секрет бота, только сервер
- TELEGRAM_CHAT_ID: подтвержденная закрытая группа, только сервер
- INTAKE_ADMIN_SECRET: временный секрет для поиска группы через POST /api/admin/telegram, передается в Authorization: Bearer. После настройки удалить из Sites
- NEXT_PUBLIC_INTAKE_DELIVERY_ENABLED: разрешает доставку в интерфейсе, production-сборка по умолчанию true. GET /api/intake/config дополнительно проверяет наличие серверного получателя; без него доступно копирование брифа

## Поведение

Посетитель может добавить контакт в исходный текст или любой ответ. Явные email, телефоны и Telegram извлекаются из переписки, показываются перед отправкой, их можно заменить. Не требуется повторно писать известный контакт. Неоднозначные контакты без явных признаков могут потребовать уточнения

Контакт отправляется вместе с брифом только по явному нажатию «Отправить заявку». Под кнопкой указана цель обработки. Оператор и формальная политика все еще требуют данных владельца, их нельзя выдумывать или считать согласованными

Перед OpenAI распознаваемые контакты маскируются. В Telegram идет итог, исходная задача и ответы, чтобы сокращение AI не теряло детали. Не обещаем распознавание любых персональных данных или идеальную работу модели

## Надежность

POST /submit проверяет контракт, Origin, согласие и контакты. Лимит 5 попыток с одного IP за час. У заявки есть sessionId, хеш содержимого, статус и позиция следующего сообщения. Повтор после успеха возвращает тот же ID, конкурентная отправка блокируется

Telegram получает обычный текст без parse_mode, ссылки не разворачиваются. Длинные заявки разбиваются на части до 4096 символов. После явного отказа Telegram клиент может повторить отправку, продолжение начинается с первого неподтвержденного фрагмента

Если сеть оборвалась и ответ неизвестен, статус uncertain. Автоматического повтора нет: Telegram мог принять сообщение. Сайт не показывает успех, заявка остается для ручной сверки. Полная гарантия exactly-once при потере ответа Telegram отсутствует. Планировщик фоновых повторов в этом этапе не подключен

Исходные данные подтвержденной посетителем заявки сохраняются в D1 с expires через 30 дней. Очистка истекших записей выполняется при следующей отправке, срок не является гарантированным временем физического удаления. Логи не содержат текст заявок или токены

Адаптивы главной: 320, 390, 600, 768, 1062, 1280, 1440 px. Переполнение проверено по геометрии документа и основных блоков. Визуально проверены телефон, планшет и desktop: перенос примеров, свободный ввод, редактирование, известные контакты, график, цвет и объем бутылки, мобильное меню
