# Подключение AI-заявки

Обновлено: 24 сентября 2026

## Решения владельца

- Работаем от обновленного main с концепцией студии «Сборка»
- Сначала подключаем и проверяем OpenAI API
- Telegram-бот и чат для заявок пока не созданы, настроим их вместе на следующем этапе
- Оператор обработки данных пока не определен. Владелец попросил вернуться к юридическим данным и политике позже, не запрашивать их повторно до этого этапа
- Пока нет согласованной политики и получателя, проверяем сценарии на тестовых данных и не включаем реальный прием контактов

## Модель

Подключен серверный маршрут для `gpt-5.4-nano`, Responses API, Structured Outputs, reasoning effort `none`. Live-проверка проводится после публикации, поскольку ключ доступен только в серверных секретах Sites

Официальная документация, проверена 24 сентября 2026:

- https://developers.openai.com/api/docs/models/gpt-5.4-nano
- https://developers.openai.com/api/docs/guides/structured-outputs

Тариф: $0,20 за миллион входных токенов, $1,25 за миллион выходных. Пример: суммарные 10 000 входных и 1 000 выходных токенов на весь диалог стоят $0,00325, без учета возможного кеширования. Это расчет, не измеренный расход

Критерии проверки: не повторяет известные данные, задает один вопрос за раз, завершает за 2-5 вопросов, не придумывает бюджет и сроки, соблюдает контракт и TOV. Проверить 10 сценариев из docs/astra-intake-prompt.md с настоящим API после подключения ключа

## Текущее состояние

- Main получен из GitHub, базовый коммит `3256c1a`
- Фронтенд вызывает `/api/intake/next`, при ошибке продолжает с локальным fallback
- Ключ `CHATGPT_PLATFORM_API_KEY` предоставлен владельцем в секретах Sites; его значение не читается и не попадает в сборку
- Worker реализован, локальные тесты контрактов и защиты пройдены
- Бриф можно изменить и скопировать, контакты пока не запрашиваются
- Telegram не подключен, тестовые сообщения не отправлялись
- Серверные ключи хранить только в секретах, никогда в `NEXT_PUBLIC_*`, браузере или Git
