# VC Studio

Сайты, веб-сервисы, интерактив и интеграции с AI.

**Next.js 15 · React 18 · TypeScript · CSS · Onest**

## Разработка

```bash
npm ci
npm run dev
npm run check:copy
npm run typecheck
npm run build
python3 -m http.server 3100 --directory out
```

Production собирается как статический Next.js export в `out/`. `.openai/hosting.json` содержит привязку к Sites. Хостинг должен поддерживать directory index для /case/, /report/ и /kit/.

## Git

Репозиторий: https://github.com/kirillsonk/vc-studio

После проверки изменений:

```bash
git status
git diff --check
git add <измененные-файлы>
git commit -m "Describe the change"
git push origin main
```

Используется системная авторизация Git. Не добавлять токены в URL, файлы или npm scripts. Публикация в Sites выполняется отдельно: push точного коммита в source repository, save version с архивом out, deploy сохраненной версии. Проверить итоговый статус публикации.

## Тексты и дизайн

BRAND.md содержит актуальные правила. AGENTS.md закрепляет постоянный TOV для будущих изменений. `npm run check:copy` проверяет запрещенные символы в исходниках и документации; он также запускается перед сборкой.

Теплый фон, графит, вермильон, Onest с кириллицей. Кнопки со срезанным углом, крупная типографика. Появление блоков однократное и не связано с прогрессом скролла. Настройка reduced motion отключает эффекты. Плавающая кнопка скрывается на первом экране и у формы.

## Бриф и контакты

Текущая форма сохраняет локальный черновик в sessionStorage. Начинается с описания задачи, дополнительные поля необязательны. Доступны резюме и редактирование. Заявки не отправляются. AI и Telegram-бот пока не подключены. Будущий сценарий и границы интеграции описаны в docs/intake-flow.md.

Проверенные публичные контакты можно указать через NEXT_PUBLIC_STUDIO_EMAIL и NEXT_PUBLIC_STUDIO_TELEGRAM. Секретов в этих переменных быть не должно.

Ссылки /?service=0#intake выбирают направление: 0 сайты, 1 сервисы, 2 интерактив, 3 интеграции. Прямой переход к форме не требует выбора категории.

## Демо и экономика

Deploy Run остается экспериментом студии. Игра запускается вручную, рекорды локальные. Страница /report содержит условный пример расходов и явно обозначает это до цифр.

Схема x2/x3/x5 на главной иллюстрирует разницу в стоимости, не является рыночной статистикой, сметой или гарантией скидки для каждого проекта. Цены в рублях и минимальный бюджет на главной отсутствуют.

## Структура

- src/app/: страницы и оболочка.
- src/site/sections/: блоки лендинга.
- src/site/brief.ts: контракт локального черновика.
- src/site/game/: игровое демо.
- src/styles/: токены и адаптивная композиция.
- project/ и chats/: исторические материалы.
