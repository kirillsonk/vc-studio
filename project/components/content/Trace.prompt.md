Production Trace — brand motif. Thin blue line through stages, current node hollow, production node green when reached. Horizontal (progress) or vertical (process/timeline).
```jsx
<Trace active={2} />
<Trace vertical steps={[<b>Задача</b>, 'Scope', 'Production', 'QA и запуск', 'Отчёт']} active={4} />
```
